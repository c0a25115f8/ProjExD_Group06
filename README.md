# プロジェクト演習II テーマD グループ06

### ■ ゲーム概要
**タイトル：アイテムキャッチ・パニック**
画面上部から次々と降ってくるアイテムを、画面下部でプレイヤーを左右に操作してキャッチする2Dアクションゲーム。
前回までのシューティングや回避ゲームとは異なり、「アイテムを回収してスコアを稼ぐ」ことを目的とする。

**【操作方法とルール】**
- **操作**: 十字キー（左右）または A/D キーでプレイヤーを左右に移動。
- **勝利条件**: 制限時間内に、目標スコアに到達すればクリア。
- **敗北条件**: お邪魔アイテム（爆弾など）を取りすぎてHPが尽きる、または時間切れ。

### ■ 実行環境・必須ライブラリ
- Python 3.x
- pygame

### ■ 実行方法
リポジトリをクローン後、ターミナルで以下のコマンドを実行。
`python main.py`
※画面サイズは 800x600、FPSは 60 で固定。

---

### ■ 【重要】共同開発のルール（全員必読）
本プロジェクトは、**「単体で動作する main.py に対して、各自が外部ファイルから機能を追加（拡張）する」**アーキテクチャを採用している。

1. **`main.py` のロジック直接改変を極力避ける**
   各自の追加機能は必ず `feature_*.py` という別ファイルにクラスとして実装する。
2. **データの受け渡しは引数で行う**
   アイテムのキャッチ判定を行う場合など、他のモジュールのデータが必要な場合は、 `item.update(player.rect)` のように引数として渡す設計にすること。
3. **ブランチ運用の徹底**
   作業は必ず `main` ブランチから自分の作業ブランチ（例: `feature/item`）を切って行う。
