# プロジェクト演習II テーマD グループ06

### ■ ゲーム概要
**タイトル：サバイバル・エスケープ**
プレイヤーを操作し、四方八方から迫りくる敵を避けながら、制限時間まで生き残る2Dサバイバルアクションゲーム。

**【操作方法とルール】**
- **操作**: 十字キー（またはWASD）でプレイヤーを上下左右に移動。
- **敗北条件**: 敵に接触するとHPが減少し、0になるとゲームオーバー。
- **勝利条件**: 画面上部のタイマーが0になるまで（60秒間）生き延びればゲームクリア。

### ■ 実行環境・必須ライブラリ
- Python 3.x
- pygame

### ■ 実行方法
リポジトリをクローン後、ターミナルで以下のコマンドを実行。
`python main.py`
※画面サイズは 800x600、FPSは 60 で固定。

### ■ 【重要】共同開発のルール（全員必読）
本プロジェクトではコンフリクト（コードの競合）や結合時のバグを防ぐため、以下のルールを厳守すること。

1. **`main.py` の直接編集禁止**
   各自の追加機能は必ず別ファイル（例: `feature_player.py`）を作成して記述する。`main.py` には、完成した別ファイルを `import` して呼び出す処理のみを追記する。
2. **他人の変数への直接アクセス禁止**
   他のクラス（主人公や敵など）の数値・状態を直接書き換えたり、読み取ったりしない。モジュール間の連携が必要な場合は、必ず引数やメソッド（関数）を介してデータを渡すこと。
3. **ブランチ運用の徹底**
   実装作業は、必ず `main` ブランチから自分の作業ブランチ（例: `feature/player`）を切って行うこと。
