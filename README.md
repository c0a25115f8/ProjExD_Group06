# プロジェクト演習II テーマD グループ06

### ■ ゲーム概要
**タイトル：サバイバル・エスケープ**
基本となる「動くプレイヤー」のベースシステム（main.py）に対し、5つの拡張機能を追加して完成させる2Dサバイバルアクション。迫りくる敵を避けながら、制限時間まで生き残ることを目的とする。

### ■ 実行環境・必須ライブラリ
- Python 3.x
- pygame

### ■ 実行方法
リポジトリをクローン後、ターミナルで以下のコマンドを実行。
`python main.py`
※画面サイズは 800x600、FPSは 60 で固定。

---

### ■ 【重要】共同開発のルール（全員必読）
本プロジェクトは、**「単体で動作する main.py に対して、各自が外部ファイルから機能を追加（拡張）する」**アーキテクチャを採用している。

1. **`main.py` のロジック直接改変を極力避ける**
   各自の追加機能は必ず `feature_*.py` という別ファイルにクラスとして実装する。`main.py` には、完成した別ファイルを `import` し、初期化・更新・描画の呼び出しを数行追記するだけに留めること。
2. **データの受け渡しは引数で行う**
   敵をプレイヤーに追従させる場合など、他のモジュールのデータが必要な場合は、`main.py` のループ内で `enemy.update(player.rect)` のように引数として渡す設計にすること。
3. **ブランチ運用の徹底**
   作業は必ず `main` ブランチから自分の作業ブランチ（例: `feature/enemy`）を切って行う。
